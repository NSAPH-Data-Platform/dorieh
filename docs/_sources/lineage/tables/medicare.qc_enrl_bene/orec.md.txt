Original Reason for Entitlement Code (OREC). Set at the time of
enrollment and invariant for the life of the beneficiary, hence a
beneficiary-level attribute. The canonical value is taken from the
earliest enrollment year (ties broken by smallest code, for
reproducibility). If the raw data is inconsistent across years the
divergence is surfaced via orec_latest / consistent_orec rather
than silently affecting joins.





## Expressions

```sql
SELECT (array_agg(orec ORDER BY year, orec))[1]
```
