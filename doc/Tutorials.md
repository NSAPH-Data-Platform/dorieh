# Dorieh Tutorials

Dorieh ships two guided tutorials:

* The **climate tutorial** — a three-part, fully reproducible walk from
  raw gridded climate data to a documented Bronze–Silver–Gold warehouse,
  built entirely on open data.
* The **Medicare tutorial** — the same design method applied to a
  production-scale claims pipeline, runnable with the publicly available
  synthetic dataset.
