# Learning Paths

The documentation serves several kinds of readers, and the best route
through it depends on what you want from Dorieh. Each path below is a
short, ordered sequence of pages — with a sentence on why each step is
there — ending with pointers for going deeper. Pick the one that sounds
like you; they all cross-reference each other, so nothing is lost by
starting in the "wrong" one.

```{toctree}
---
maxdepth: 1
caption: Choose your path
---
Researchers and analysts <researcher>
Pipeline developers <developer>
Platform operators <operator>
Readers of the book <book-reader>
Reviewers and auditors <auditor>
```

If none of these fit, the general reading order is the one the
[front page](../index.md) is organized around: start with
[why the platform exists](../rationale.md), then
[the Dorieh approach](../concepts.md), then the
[tutorials](../Tutorials.md).
