# Python Packages Included in the Platform  

This section is the API-level reference for the Python packages that
make up Dorieh, grouped by area; for the concepts these packages
implement, start from [The Dorieh approach](concepts.md).

```{toctree}
---
maxdepth: 1
caption: Contents
---
General purpose utilities <utils>
Data platform components <CoreLibrary>
GIS utilities <gis>
Health data manipulation tools <CMSLibrary>
Raster data tools (climate and exposure) <rasters>
```
