# Column medicare.qc_enrl_bene.curec_latest

## Overview of column curec_latest in table medicare.qc_enrl_bene 

|                               |                        |
| ----------------------------- | ---------------------- |
| Table                         | [medicare.qc_enrl_bene](../medicare.qc_enrl_bene.md)           |
| Qualified name                | medicare.qc_enrl_bene.curec_latest  |
| Datatype                      | string        |
| Column type | computed |


Non-null only when duplicate source records disagree on CUREC
within a (bene_id, year, state) group. Drives consistent_curec.
Defensive / future-proofing: this multiplicity does not occur in
the synthetic dataset (every group is a single row) but can arise
in real Medicare data from overlapping or reissued MBSF files,
where MAX(curec) would otherwise silently pick one value.
